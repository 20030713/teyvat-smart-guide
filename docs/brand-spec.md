# 提瓦特智游视觉与品牌边界

## 定位

这是非官方的学习与作品集项目。视觉目标是营造“开放世界奇幻旅行社区”的氛围，而非复刻《原神》客户端界面。项目不使用官方 Logo、角色立绘、图标、地图截图、剧情文本或音乐，也不暗示与米哈游存在合作关系。

## 视觉系统

- 核心隐喻：冒险者地图册、旅途手账、自然博物志。
- 主色：深海蓝绿 `#173d43`、羊皮纸暖白 `#f8f5ed`、旧金 `#b89658`、风元素青 `#4f908d`。
- 字体：Noto Serif SC（标题）与 Manrope（界面正文），均通过 Google Fonts 公共 CDN 加载，字体遵循 SIL Open Font License。
- 图形：细线、圆形罗盘、地形网格、克制的金属色标记；不照搬游戏元素图标。
- 动效：抽屉、卡片位移、图片轻微缩放；避免高强度发光、紫色科技渐变与堆叠装饰。

地点照片来自 Pexels 公共图片 CDN。详情与来源见 `docs/credits.md`。上线前应再次核查素材许可与链接有效性；若长期运营，建议下载到自有对象存储并保留作者和许可元数据。
