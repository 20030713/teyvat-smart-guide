# 提瓦特智游视觉与品牌边界

## 定位

这是非官方、非商业的学习与作品集项目。根据项目方要求，界面使用公开发布的《原神》宣传图与游戏场景图来建立明确的提瓦特氛围，但不暗示与米哈游、HoYoverse 存在合作、授权或官方关系。

## 视觉系统

- 核心体验：冒险家协会委托面板、传送锚点探索、七国旅行札记。
- 主色：深蓝灰 `#313b50`、冰雪蓝 `#709cc6`、象牙白 `#f6f3ea`、鎏金 `#d3bc8e`。
- 字体：Noto Serif SC 与 Cinzel，均通过 Google Fonts 公共 CDN 加载。
- 图形：官方宣传主视觉、浅色描边面板、金色细线、元素国度色与克制的冰晶光效。
- 交互文案：统一使用“冒险家协会、传送锚点、每日委托、冒险阅历、派蒙领航”等世界观表达。

## 使用边界

官方与社区公开素材的著作权、商标权仍归原权利人所有；公开访问不等于开放授权。仓库保留来源清单，仅用于本地演示、学习和作品集展示。如需商业部署，应替换为已取得书面授权的素材并完成法律审查。
